## ★ Highlighted

### Expense Tracker — `C#` `.NET 10` `React` `PostgreSQL` `Docker` `Cloudflare R2`

Full-stack expense tracker: a React + Vite SPA talking to an ASP.NET Core REST API. Google sign-in exchanged for my own JWT, receipts stored in Cloudflare R2, both services in Docker on Render.

- Code: [najazul/expense-tracker](https://github.com/najazul/expense-tracker)
- Live: [expense-tracker.normanjazuljr.dev](https://expense-tracker.normanjazuljr.dev)
- How I built it: [/blog expense-tracker](cmd:/blog expense-tracker)

### drAIn — `Next.js` `Supabase` `Python` `Deno` · 🏆 PJDSC 2025 Champion

SWMM-based flood simulation and citizen-reporting platform that helps planners find weak points in urban drainage. I built the serverless geocoding worker and the early K-means flood-hotspot model.

- Code: [kiloumanjaro/drAIn](https://github.com/kiloumanjaro/drAIn)
- Live: [ai-drain.vercel.app](https://ai-drain.vercel.app/)
- How I built it: [/blog drain](cmd:/blog drain)

### Skolaroid — `TypeScript` `Next.js` `Supabase` `Prisma` · 🏆 SE Expo 2026 Best Startup

Location-based campus memory sharing. I owned the backend side: CRUD API routes, route protection, domain-restricted Google sign-in, and the invitation system.

- Code: [kiloumanjaro/Skolaroid](https://github.com/kiloumanjaro/Skolaroid)
- Live: [skolaroid.vercel.app](https://skolaroid.vercel.app)
- How I built it: [/blog skolaroid](cmd:/blog skolaroid)
