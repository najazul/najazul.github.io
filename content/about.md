# Norman Jazul Jr.

> Fullstack developer · backend specialist · cloud & security enthusiast

Hi! I'm Norman, a Computer Science student at the **University of the Philippines Cebu** and a **DOST-SEI scholar**. I build full-stack apps, but my favorite part is the backend: the API, the database schema, the auth flow, and the infrastructure that keeps it all running.

I like systems that are boring in the good way: they validate every input, keep secrets out of the code, fail closed, and stay up while nobody is watching.

## What I focus on

- **Backend** — REST APIs in C# / ASP.NET Core, Node.js / Express, and FastAPI. PostgreSQL schema design with EF Core and Prisma.
- **Auth & security** — Google OAuth, JWT, route protection, role-based permissions, secret handling. I treat security as a feature, not an afterthought.
- **Cloud** — Docker, Render, Vercel, Supabase, Cloudflare (R2, DNS, SSL), plus AWS fundamentals (Lambda, API Gateway, S3, DynamoDB, CloudWatch).
- **Frontend** — React, Next.js, TanStack Router, Tailwind. Enough to ship the whole product end to end.
